# 抖音福袋助手 · 使用说明

## 运行要求

| 项目 | 要求 |
|:---|:---|
| 操作系统 | Windows 10 / 11（64 位） |
| 浏览器 | Google Chrome（未安装时程序会提示下载地址） |
| 网络 | 能正常访问抖音直播 |
| 抖音账号 | 扫一次码即可，登录态保存 30 天 |

程序不联网上报任何数据，所有记录都保存在程序所在文件夹里。

## 首次使用

1. 双击 `douyin-fudai.exe`
2. 程序自动检测 Chrome，弹出一个 Chrome 窗口
3. 在窗口里点右上角「登录」→ 用抖音 App 扫码
4. 登录成功后窗口自动关闭，程序开始工作
5. 浏览器打开 **http://127.0.0.1:8899** 查看实时看板

控制台窗口不要关闭，关掉就等于停止运行。

## 看板能看到什么

| 区块 | 含义 |
|:---|:---|
| 今日遭遇 / 参与成功 / 中奖 | 今天遇到多少个福袋、成功参与几个、中了几个 |
| 当前监控 | 正在蹲守哪个直播间、在线人数、当前门槛 |
| 福袋事件 | 最近遇到的所有福袋及处理结果 |
| 指定主播 | 你重点关注的主播在播状态 |
| 执行能力 | 粉丝团加入成功率、关注成功率、抖币消耗、开奖结果 |
| 主播档案 | 学习到的房间历史，累积越多选得越准 |

## 运行策略说明

- **在线人数门槛**：白天 8000，晚间 19-24 点 50000
- **抢哪些福袋**：评论型、评论+关注型、粉丝团型都会尝试
- **会花钱的操作**：加入粉丝团消耗 1 抖币/次（抖币消耗在看板可见）
- **会关注主播**：参与成功后才关注，不会乱关注

## 常见问题

**Q：双击后窗口一闪就没了？**
A：说明缺少 Chrome 或启动失败。用命令行运行 `douyin-fudai.exe status` 能看到具体原因。

**Q：提示登录失效？**
A：抖音登录态约 30 天过期。重新运行程序，它会自动重新弹出扫码窗口。

**Q：看板打不开？**
A：确认控制台窗口还在。若 8899 端口被占用，程序会提示。

**Q：能同时挂多个抖音号吗？**
A：当前版本单账号。多账号需要多开程序并放在不同文件夹（各自独立的 chrome-profile）。

**Q：换电脑怎么迁移？**
A：把整个文件夹拷贝过去即可。登录态、学习档案、历史记录都在里面。

## 目录结构

```
douyin-fudai.exe        主程序
data/                   学习档案、参与记录、中奖记录
douyin-auto/            运行日志、截图、状态文件
douyin-auto/chrome-profile/   登录态（不要删除，删了要重新扫码）
```

## 停止运行

直接关闭控制台窗口，或在窗口里按 `Ctrl+C`。
